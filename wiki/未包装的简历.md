# mawoagent 项目经历（不含论文指标）

这份版本只写 mawoagent 仓库中可查看的功能实现，不使用 DeepAgent 论文的 GAIA / HLE 分数。需要带论文数字说明评测设计时，可参考[数据增强版](简历包装.md)，并注明数据来源。

## 简历正式版

**mawoagent：支持会话记忆折叠与 Skills 自进化的本地 Coding Agent Runtime**  
技术栈：Python、AsyncIO、OpenAI SDK、Anthropic SDK、MCP、JSON-RPC、Docker

mawoagent：集成自主会话记忆折叠、Skills 自进化、MCP 与子 Agent 的自进化 Harness Agent 技术栈：Python、OpenAI SDK、Anthropic SDK、MCP、JSON-RPC、Docker、Skills

- 从零实现 Agentic Harness，统一编排模型推理、tool call 解析、权限检查、工具执行、结果回写、会话恢复和上下文压缩，支持 OpenAI / Anthropic 双协议、MCP、Plan Mode 和子 Agent。
- 设计自主会话记忆折叠机制，将其作为长程任务中的状态重组和策略重启能力，而非单纯上下文压缩；通过 episode_memory、working_memory、tool_memory 保留任务进度、当前工作状态和工具经验，使 Agent 能在上下文受限、工具反复失败或策略变化时通过 compact_context 主动折叠并继续推进任务。
- 实现在线 Skills 自进化链路，通过 pending window 捕捉用户后续反馈，结合“抽取器 / 维护器”完成候选抽取、相似检索、add / merge / discard 决策和 SKILL.md 落盘。
- 实现 Memory + Skills 分层长期上下文，Memory 保存项目事实和用户偏好，Skills 保存可复用任务流程，并支持 BM25-lite 检索、inline / fork 执行和长期记忆召回。
- 构建 Skills 自进化质量评测机制，基于来源追踪构造 replay 样本池，结合规则评测、LLM judge、候选版本试跑和优胜版本登记，保证能力沉淀可回放、可比较、可审计。

## 简历精简版

**mawoagent：本地 Coding Agent Runtime**

- 扩展 Python Agent Runtime，统一处理模型、工具、权限、会话和上下文；支持双协议、MCP 与子 Agent。
- 实现三层会话记忆折叠，使 Agent 能保留长程任务的进度、工作状态和工具经验。
- 实现用户反馈驱动的 Skills 自进化和基于 replay、规则与 LLM judge 的质量观察链路。

## 面试简述

mawoagent 是一个基于开源 Agent Runtime 扩展的本地 Coding Agent。我重点做了三层会话记忆折叠和 Skills 自进化：前者把长对话中的任务进度、当前状态和工具经验保存成结构化信息，后者把稳定的用户反馈沉淀为可复用的 Skill。项目中也整理了 GAIA 和 HLE 题目，后续可以在固定模型与工具配置下自行评测折叠效果。
