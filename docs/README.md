## 约定

- **语言**：仓库内部文档用中文；`README.md` 保留中英双语，因为它是对外入口。
- **命名**：现行文档用主题名（`skills.md`）；历史文档带日期（`change-log-2026-10-15.md`）。
- **状态**：历史文档开头都有「历史记录」标注，新增存档请照做。
- **链接**：文档之间用相对路径互链，移动文件时同步修改，避免死链。
