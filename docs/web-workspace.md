# 本地 Web 工作台

> 返回：[文档索引](README.md)

采用石墨深色工作台：米白文字、香槟金主操作、集中式任务入口与分层任务详情。使用原生 HTML / CSS / JavaScript 和 Python 标准库服务，不需要安装 Node.js 前端依赖或增加 Python 包。

## 启动

在 mawoagent 项目根目录执行：

```bash
source .venv/bin/activate
python -m agents.web
```

打开 http://127.0.0.1:8765 。端口被占用时可运行 `python -m agents.web --port 8766`。Ctrl+C 取消前台任务、关闭模型连接并停止服务。

模型配置沿用 CLI 的 `.env` 与环境变量，不在网页录入或显示密钥。没有 API Key 也能查看工作台和已有数据，发送任务前会提示补全配置。修改模型环境配置后需要重启服务。

## 已实现

- 新建、切换与恢复当前项目的会话；连续回复通过 SSE 实时展示，重连后读取当前状态。
- 用户消息在右侧、Agent 回复在左侧；模型的结构化思考内容使用独立的默认折叠区，不混入正文、经验抽取或评测答案。旧版混入 `[thinking]` 的 Web 记录从已保存的协议正文恢复显示，不猜测思考与回答的文本边界。
- 回复支持标题、列表、代码块、表格与安全链接；宽表格在消息内部横向滚动，原始 HTML 作为文本展示。
- 长对话仅更新变化的消息节点。停留在底部时跟随新回复，手动上滑后保持阅读位置；“回到最新消息”恢复跟随。会话切换保留各自的阅读位置，工具结果的内部滚动和计划修改意见在流式更新时保留。
- 展开工具参数和执行结果；写文件与 Shell 等操作保留 Runtime 的检查，通过页面逐次允许或拒绝。
- 停止任务，取消未完成的模型请求和授权等待；计划完成后可审核执行、反馈修改或取消。
- 流式重试会撤回失败尝试的临时回答和思考显示；恢复会话时，未完成工具显示结果未知，需要先核对实际状态。
- 切换默认权限、只读计划、自动接受编辑、自动拒绝授权；运行时禁用切换。
- 从真实工具结果显示执行时间线、成功写入的文件列表和会话 Token。
- 查看 Skills、候选与长期记忆，搜索并查看详情，手动调用允许调用的 Skill。
- 查看已有评测报告、启动评测；候选详情提供评测通过后的申请发布和明确的人工审核发布入口，沿用候选哈希检查与发布门槛。
- 添加最多 5 个 UTF-8 文本附件；每个不超过 60 KB，总输入不超过 100,000 字符。附件加入任务文本，不会自动上传或写入项目。
- 草稿和附件按会话保存；发送成功只清理已提交的草稿版本，等待期间的新输入继续保留。附件读取期间切换会话，完成结果仍归属于原会话。
- 桌面任务侧栏与手机抽屉导航，键盘发送、⌘ / Ctrl + K 新会话和减少动态效果支持。

## 运行边界

服务只监听 127.0.0.1，并校验 Host、Origin、本地会话 Cookie 和 POST 的 CSRF 标识。不得将它直接代理为公共服务；现有工具 Runtime 本身具有操作本机文件与 Shell 的能力，并不是面向多用户的沙箱。

一个服务固定对应启动目录。Runtime 具有共享的工具和 Skills 状态，因此同一项目同时只执行一个前台任务；切换会话不会停止原任务。关闭浏览器不等于取消任务，重新打开后可以继续授权或停止；无人响应的授权十分钟后拒绝。

会话沿用 `~/.mawoagent/sessions/`，Web 显示记录存放在同一 JSON 的 `webEntries` 中。现有 CLI 会话可以在网页恢复，API 协议不一致时沿用 Runtime 的拒绝恢复行为。页面不自动运行模型；用户发送任务或启动评测才会产生模型调用。评测不是独立的泛化能力证明。

文件侧栏表示本次任务中成功的直接写入 / 编辑；Shell 或子 Agent 产生的文件变化不能保证由此列表完整识别。评测页展示已保存的报告，需刷新读取后台更新。

SSE 首次连接和重连发送完整快照，之后按 revision 发送增量，文本只发送新增后缀。服务端保留最多 128 个事件、2 MiB 的补发队列；版本缺失或服务重启时重新获取快照，空闲时只发送注释心跳。单条回答和思考的 Web 预览最多 128,000 字符，达到上限会显示提示；模型回答的协议历史不因此截断。

## 验证

```bash
python -m unittest discover -s tests
node --check web/app.js
node --test web/tests/*.test.mjs
```

`tests/test_web.py` 使用模拟模型与执行器验证流式状态、允许 / 拒绝、停止、会话恢复、权限切换、单任务执行和 HTTP 访问边界，不消耗模型费用。

`tests/test_web_v3.py` 和 `web/tests/conversation-state.test.mjs` 补充长会话增量大小、HTTP 快照/增量/心跳/重连、流式回退、版本重置及草稿和附件异步竞态测试。
