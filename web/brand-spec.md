# mawoagent Web · 石墨工作台

本次属于保留功能契约的视觉重设计。沿用已有 mawoagent 文字字标、深色工作台及暖金强调色，不新增品牌图形或外部字体依赖。

## 设计判断

- 使用者：在电脑上持续阅读、执行、审核代码任务的开发者。
- 页面角色：日常工作界面；欢迎区提供开始任务的入口，进入会话后让正文和工具执行成为主角。
- 原版问题：灰绿色面板层次接近；欢迎标题重复；三栏偏拥挤；导航、消息和详情的权重不够清晰。
- 视觉变化 4/10：保留三栏骨架，重做欢迎区、输入框和组件比例。
- 动态强度 2/10：仅 160ms 状态反馈，支持 reduced-motion。
- 信息密度 7/10：保留全部操作；收紧导航，减轻次要信息的视觉权重。
- 图像依赖 1/10：保留真实字标和现有线性图标体系，无装饰插画。
- 品牌保留 8/10：继续使用深色、暖金、中文界面与原有导航名称。

## 视觉系统

- 主画布 `#191a1c`，侧栏 `#131416`，次级底色 `#1e1f21`，操作表面 `#242527`。
- 正文 `#edece8`，辅助文字 `#a1a2a8`，次要文字 `#85868e`，分隔线 `#303134`。
- 香槟金 `#e7c28c` 用于主操作与当前焦点；执行成功 `#9bbcaf`，错误 `#e7a096`。
- 中文 PingFang SC / Noto Sans SC；字标 Avenir Next；代码 SFMono-Regular / Consolas。均使用本地字体回退。
- 间距以 4 / 8 px 为基础。按钮 7–9px 圆角，工具与入口 9–10px，输入框 14px。
- 阴影仅用于输入框、悬浮反馈、浮层与弹窗；无发光、背景图或大面积渐变。
- 桌面导航 224px、详情 262px；宽屏分别 244px / 290px。960px 以下详情按需展开，680px 以下导航改为抽屉。

## 保留契约

保留全部 DOM IDs、data 操作选择器、页面入口、权限选项及授权行为。消息继续按 key 局部更新，草稿、附件、滚动位置、工具展开态和 SSE 会话同步保持原有机制。

所有会话、Skills、记忆、评测与用量均来自实际 Runtime 和磁盘数据；空状态不伪造数据。旧运行进程需要重启后才能识别近期新增的 JavaScript 模块路由。
